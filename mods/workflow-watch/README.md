# workflow-watch

A mod (a plugin of function hooks) that opens with every session and tracks everything happening live: main-thread turns (`turn:N`), skills fired (`skill:<name>`), spawned subagents (`agent:<description>`), git commits (`commit:<sha>`), and Workflow stages (`plan`, `scout`, `spec`, `build`, `measure`, `refute`, `arbiter`, `fix`, `close`). It draws a live `Tracker` pane, a band above the prompt while stages or subagents run, the status line, and a toast as each workflow stage, background subagent, or commit finishes. `/tracker` (or `/workflow-watch`) opens the pane and prints the same report as text, which is all the mobile app shows.

When two or more items are present, the pane opens with a compact Unicode timeline waterfall (`░░████░░`) showing each item's span and duration on the session's shared clock. Below that, each item gets one block in chronological order, and the phase name (`Turn N`, `Skill · <name>`, or the Workflow phase) appears as a divider wherever it changes. The first line of a block shows the state as a glyph and a word, the item label, the model alias and the id it resolved to, and the effort level. The states are ▶ running, ✓ done, ! failed, ! disputed (a fix round that left findings for the arbiter) and ✗ no result (a stage that returned nothing, or died before returning, say on a session limit). Two indented lines follow: the one-line result (for background subagents, extracted from `SubagentHandback` without counting the handback as a tool call) and the details (`Ran for 0:46 · 5 tools · 0.8k tokens`, or `Running for 0:12 · 3 calls · Bash npm test`).

It reads Claude Code's files under `~/.claude/projects/<project>/` every two seconds: `<session>.jsonl` for main-thread turns, skills, agent spawns and commits, `<session>/subagents/agent-<id>.{meta.json,jsonl}` for spawned subagents, and `<session>/subagents/workflows/<run>/journal.jsonl` (plus its `agent-<id>` files) for Workflow runs. On Windows inside the VS Code extension host (where `HOME` is unset), it resolves the user directory from `USERPROFILE`. It also parses Antigravity extension transcripts (`~/.gemini/antigravity/brain/<id>/.system_generated/logs/transcript.jsonl` or `transcript_full.jsonl`) and links spawned subagent conversations automatically.

Install with the marketplace (`/plugin install workflow-watch@alonbaron`) or load it for one session with `claude --plugin-dir <this folder>`. Works both in the terminal CLI and inside the VS Code Claude Code and Antigravity extensions. The pane needs a terminal of 144 columns, or `/tracker` (`/workflow-watch`) to seat it narrower. `scripts/tracker.mjs` renders the same session or workflow feed to HTML or PNG from outside a session with auto-reload for VS Code Simple Browser or Live Preview (`--watch`).

Check it: `claude plugin validate mods/workflow-watch`, `claude plugin test mods/workflow-watch`, `tsc -p mods/workflow-watch` once a session has laid the types beside it.
